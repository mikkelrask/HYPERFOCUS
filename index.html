HYPERFOCUS is a keyboard-driven project launcher and scaffolder. Browse all your repos with fuzzy search, jump straight into a custom tmux layout, and spin up new projects from a configurable template — without touching your mouse.

Requires Go 1.21+, tmux, and git. Ensure ~/go/bin is on your $PATH, or symlink the binary somewhere that is.

FEATURES dev branch

Instant launch

Select a project and drop straight into your custom tmux session layout. No setup, no waiting.

Fuzzy search

Type to filter your project list in real time. Find any repo in milliseconds.

Project scaffolding

Press Ctrl+n and follow the wizard — picks your language, framework, and runs git init.

Adopt existing repos

Register any directory with hf --adopt . and it gets a launch script automatically.

Per-project scripts

Each project gets its own launch.sh. Edit it with Ctrl+e to tune the tmux layout.

Mouse support

Click to select and open a project — for the rare moments the keyboard isn't enough.

KEYBINDS
↑ ↓ Navigate project list
Enter Open selected project (runs its launch script)
Ctrl+n Create a new project via the wizard
Ctrl+a Adopt an existing repository (path + tab completion)
Ctrl+e Edit selected project's launch script in $EDITOR
Ctrl+q / Ctrl+c Quit
Esc Clear search / quit
BUILD FROM SOURCE
# clone and build
$ git clone https://github.com/mikkelrask/hyperfocus ~/Repos/hf
$ cd ~/Repos/hf
$ go build -o hf .
$ cp hf ~/.local/bin/

# then launch
$ hf
